TypeScript architecture linter for AI coding agents

typie hyperlinter

Keep your agent’s codebase maintainable.

Find dependency cycles, duplicated functions, and oversized public APIs across your TypeScript repository. Errors return a failing exit code for your agent or CI to act on.

Install Hyperlinter ↓

What it catches

  • Dependency cyclesCircular imports and unusually coupled modules.
  • Oversized APIsPublic-surface growth, unused exports, and boundary violations.
  • Duplicated or unused functionsSource clones and unreachable top-level implementations.

Try it in your TypeScript repository

Requires Node.js 22+ and a tsconfig.json. Run from your repository root:

git submodule add https://github.com/flintwinters/hyperlinter.git tools/hyperlint
npm --prefix tools/hyperlint ci --include=dev
./tools/hyperlint/node_modules/.bin/tsx tools/hyperlint/src/cli.ts

Review the default policy: each source directory needs an index entrypoint. CSS files and inline JSX styles are rejected.

Setup, commands & limitations ↗

Optional semantic grouping uses OpenRouter embeddings to suggest agent examination. It sends function source to the provider and requires an API key; its experimental warnings never block. Ordinary checks need no model or API key.
