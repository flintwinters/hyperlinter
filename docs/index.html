TypeScript architecture linter for AI coding agents

typie hyperlinter

Keep your agent’s codebase maintainable.

Catch tangled dependencies, duplicated logic, dead code, and oversized APIs. Give your coding agent concrete diagnostics to act on as your repository grows.

What it catches

  • APIs that keep growingUnused exports, public-surface growth, and broken module boundaries.
  • Code that becomes hard to changeDependency cycles, coupling outliers, and duplicated implementations.
  • Responsibilities that drift apartDead functions and low-cohesion modules, using compiler and reference evidence.

Try it in your TypeScript repository

Requires Node.js 20+ and a tsconfig.json. Run from your repository root:

git submodule add https://github.com/flintwinters/hyperlinter.git tools/hyperlint
npm --prefix tools/hyperlint install
npx tsx tools/hyperlint/src/cli.ts

Review the default policy: blocking rules include module entrypoints and styling constraints.

Setup, commands & limitations ↗

Optional semantic grouping uses OpenRouter embeddings to suggest agent examination. It sends function source to the provider and requires an API key; its experimental warnings never block. Ordinary checks need no model or API key.
